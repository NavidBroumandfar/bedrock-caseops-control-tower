# Code of Conduct

## Our Pledge

Contributors and maintainers are expected to participate respectfully and
professionally. This project welcomes technical discussion, critique, and
correction, but not harassment, personal attacks, or disclosure of private
credentials or cloud resources.

## Expected Behavior

- Be direct and constructive.
- Keep feedback focused on code, architecture, documentation, security, and
  reproducibility.
- Respect privacy: do not post AWS account IDs, ARNs, credentials, private logs,
  generated Lambda responses, or other sensitive operational artifacts.
- Assume good intent while still being precise about risks and defects.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Publishing secrets, private cloud identifiers, or exploit details.
- Repeated off-topic comments that prevent useful technical work.
- Misrepresenting the project as a native Amazon Bedrock Agents deployment when
  the mainline architecture is custom Python orchestration.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests;
or block participants when needed to protect the project and its users.

Security concerns should follow `SECURITY.md` rather than public disclosure.
